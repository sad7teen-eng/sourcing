Import automatique : glissez ce bouton dans votre barre de favoris → → Sourcing. Sur une annonce Chrono24 : le favori copie l'annonce (nouvelle ligne). Sur une page de recherche Chrono24, WatchSalon ou eBay (ou dans un groupe Facebook : cliquez, faites défiler, puis « Terminer et copier ») (ex : « 126515LN meteorite ») : le favori relève toutes les annonces trouvées et calcule la cote du marché de la montre correspondante (Europe uniquement dans l'onglet Europe). Puis « Importer » et collez.
Photo : cliquez sur la case puis collez (Cmd + V) ou glissez une image. Marge = prix de vente − prix d'achat (négocié, sinon demandé) − frais. Sans prix de vente, le prix moyen du marché est utilisé.
